Resonite Export Viewer (Windows 版)

Resonite Account Downloader でダウンロードしたアカウントデータを、ブラウザで閲覧するツールです。

■ 使い方

1. Resonite Account Downloader でアカウントデータをダウンロードする
   https://github.com/Yellow-Dog-Man/ResoniteAccountDownloader
2. ダウンロードしたフォルダ (U-xxx と Assets が入っているフォルダ。例: ResoniteDownload) を
   ResoniteViewer.exe にドラッグ&ドロップする
   (ResoniteDownload フォルダを ResoniteViewer.exe と同じ場所に置いて、ダブルクリックでも起動できます)
3. ブラウザが自動で開きます。開かない場合は http://127.0.0.1:8765/ を開いてください
4. 終了するときは、黒いウィンドウを閉じてください

■ 注意

- このフォルダの中のファイル (ResoniteViewer.exe 以外も含む) はすべて動作に必要です。exe だけを移動しないでください
- 初回起動時に Windows の SmartScreen が「Windows によって PC が保護されました」と表示することがあります。
  「詳細情報」→「実行」で起動できます
